# Audio Devices Extension Changelog

## 0.1

- Initial release: one runnable item per audio device and role (output / input), verified
  switching, Use for Sound Output / Sound Input / Alert Sounds actions, Route alert sounds with
  output setting, per-device Hide from Tuna / Show in Tuna, browse grouping by role, and live
  refresh when devices connect, disconnect, or are switched elsewhere.
- Native Core Audio (macOS 15 typed API); no Homebrew dependency.
- Requires Tuna 0.96 / TunaKit 1.22.0 and macOS 15.
